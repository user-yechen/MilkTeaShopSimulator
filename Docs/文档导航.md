## 6. 维护规则

1. 改数值 → 更新 [数据手册.md](数据手册.md)
2. 改 public 接口 → 更新 [脚本接口.md](脚本接口.md)
3. 改风格/色板 → 更新 [美术风格.md](美术风格.md) 并同步 `美术参考/色板.png`
4. 新增流程/角色 → 更新 [团队架构.md](团队架构.md)
5. 每个版本结束 → 更新 [上下文.txt](../Assets/上下文.txt) 的「当前状态」与「变更记录」
6. 新文档 → 在本表登记一行

> **上下文.txt 的边界**：只写「当前状态、待办、经验教训、变更记录」。
> 数值/坐标进数据手册，接口进脚本接口，风格进美术风格；上下文只留链接，不复制内容。
> 同一事实只允许有一个权威出处，发现重复就删掉副本并改成链接。

> 文档之间用相对链接互相引用；移动文件时记得改链接。
