# 文案 Agent 手册

> 2026-11-27　｜　负责游戏内所有文本：润色、拆分条目、产出可导入 Unity 的文案表
> 配套：[数据手册.md](../数据手册.md)、[团队架构.md](../团队架构.md)

---

## 1. 角色与边界

| 做什么 | 不做什么 |
|---|---|
| 把你写的大纲润色成游戏内文本 | 不改数值、不改代码逻辑 |
| 拆成「一条文案 = 一个 key」 | 不自己发明系统（新面板/新功能） |
| 产出 UTF-8 CSV 文案表 | 不直接改场景里的 Text 组件 |
| 控制字数、统一标点与口吻 | 不做多语言翻译（预留 en 列） |

**唯一交付物**：`Assets/Resources/文案/文案表.csv`

---

## 2. 输入与输出

- 输入：你在 `Docs/文案/大纲.md`（或直接贴在对话里）写的大纲/草稿
- 输出：
  1. `Assets/Resources/文案/文案表.csv`（覆盖写，保留旧 key）
  2. 一段「本次新增/修改了哪些 key」的说明
  3. 校验结果（0 错误才允许交接）

---

## 3. 文案表格式

CSV，UTF-8（可带 BOM，Excel 友好），第一行表头固定：

```csv
key,category,zh,en,speaker,maxChars,note
ui.shop.title,UI,商店,,,8,左上角图标名
ui.day.end_title,UI,今日营业结束,,,12,打烊面板标题
ui.day.end_body,UI,今日营收：{0} 元\n钱包：{1} 元,,,40,支持 {0} {1} 占位符
npc.order.greeting.01,顾客,欢迎光临，想喝点什么？,,顾客,20,进店第一句
```

| 列 | 必填 | 说明 |
|---|---|---|
| `key` | 是 | 全局唯一，格式 `模块.对象.字段`，小写+点+下划线 |
| `category` | 是 | UI / 顾客 / 商店 / 提示 / 教学 / 系统 |
| `zh` | 是 | 中文文案；换行用 `\n` 两个字符 |
| `en` | 否 | 预留，暂留空 |
| `speaker` | 否 | 说话人（顾客/店主/系统），用于气泡或字幕 |
| `maxChars` | 否 | 该处 UI 的字数上限，校验用 |
| `note` | 否 | 使用场景、语气要求 |

### key 命名规范

```
模块.对象.字段[.序号]
ui.shop.title
ui.button.confirm
npc.order.greeting.01
tip.fluid.not_enough
tutorial.step.pick_cup
```

- 全小写；只用 `.` `_` `[a-z0-9]`
- 同一对象的多个变体用两位序号：`.01` `.02`
- **key 一旦被代码引用就不能改名**（改名等于删文案），需要改就新增 key、旧 key 标记废弃

---

## 4. 文风

- 短句、口语，像店员说话，不像说明书
- 一句一个意思；超过 20 字考虑拆句
- 标点用全角：，。？！；：
- 数字用阿拉伯数字；金额写「12 元」
- 不用 emoji、不用颜文字、不用网络梗
- 称呼统一：玩家=「你」，顾客=「客人」
- 提示类文案先说结论再说原因：「牛奶不够了，去货架补一瓶」

---

## 5. 工作流

```
你给大纲
  → 拆条目：一条文案一个 key
  → 填表（zh / category / maxChars / note）
  → 跑校验：菜单「奶茶店/文案/校验并生成 Key」
  → 0 错误 → 交付：CSV + key 变更说明
  → 有错 → 修正后重跑
```

程序侧只做两件事：

1. 用 `GText.Get("ui.shop.title")` 取文案
2. 需要拼接时用 `GText.Format("ui.day.end_body", revenue, wallet)`

---

## 6. 校验规则（工具自动检查）

| 规则 | 处理 |
|---|---|
| key 重复 | 报错 |
| key 格式非法 | 报错 |
| zh 为空 | 报错 |
| zh 超过 maxChars | 报错 |
| `{0}` 占位符数量与 note 不符 | 警告 |
| 表头缺列 | 报错 |

校验命令：菜单 **奶茶店/文案/校验并生成 Key**，或命令行
`-executeMethod TextImportTool.ImportForCI`（失败返回非 0，可进 CI）。

---

## 7. 调用模板

> 用文案 agent 把我 `Docs/文案/大纲.md` 里的大纲润色成文案表，按现有格式，跑校验，给我 key 变更说明。

子 Agent 提示词：

```
你是文案 Agent。先读 Docs/Agents/文案Agent.md 与 Assets/Resources/文案/文案表.csv。
任务：把 <大纲路径> 润色并拆成条目，写入 CSV（保留已有 key，新增 key 按规范）。
要求：口语、短句、全角标点、控制 maxChars；不改代码、不改数值。
完成后跑 TextImportTool 校验，报告新增/修改的 key 与校验结果。
```
