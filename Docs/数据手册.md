## 1. 时间

| 项 | 值 | 权威来源 |
|---|---|---|
| 时间流速 | 现实 1 秒 = 游戏 1 分钟 | `GameClock.gameSecondsPerRealSecond = 60` |
| 营业时段 | 08:00 – 16:00 | `ShopManager.openHour/closeHour` |
| 首位顾客 | 09:00 起 | `PasserbyWalk.firstHour/firstMinute` |
| 存档间隔 | 每 5 秒 | `GameClock.saveIntervalSeconds = 5` |
| 日期牌动画 | 展开停留 3 秒 | `GameClock.dayBoardOpenSeconds = 3` |
| 打烊行为 | 停钟 → 营收入钱包 → 弹结算面板 | `ShopManager.EndDay()` |

> 一天实际时长 = 8 小时 × 60 分 × 1 秒/分 = **480 秒（8 分钟）**。

## 5. 设备

| 设备 | 关键参数 | 来源 |
|---|---|---|
| 奶茶机 | 流体罐容量 20,000 ml/种；首次接触建空罐；每日清空 | `tankCapacityMl`、`ClearAllFluids` |
| 奶茶机 | 注液动画 1.2 s；无出料口时只染色 + SetFillLevel | `PourFluid`、`TeaMachine.PourColored` |

| 冰格 | 需前制作台 ≥ 2 级解锁 | `IceTray.unlockLevel = 2` |
| 前台 | 成品按「杯型 + 液体」匹配取走 | `CounterCupDisplay.HasCup/TakeCup` |
| 杯架 | 每层 5 个，间距 0.05 m | `CupStack` |
| 补液 | 牛奶 1000 ml/瓶；满罐不出按钮 | `FluidProvider.mlPerUnit` |

|---|---|

| 迁移风险 | 改包名/公司名会换目录，旧档不自动迁移 |
