# 训练成果

> AI 生成的 2D 资产成品库。和 `训练素材/` 同级：素材进、成品出。
> 生成工具：本地 **ComfyUI**（`D:\ComfyUI`），通过 `Tools/ComfyUI/generate.py` 调用。

---

## 目录

```
训练成果/
  图像/
    设备/   加热机、制冰机、封口机等设备概念图
    UI/     面板、按钮、弹窗背景
    图标/   功能图标、货币、订单图标
```

- 命名：`<对象>_<变体>_<序号>.png`，如 `加热机_概念_01.png`
- 每张图旁边可放同名 `.txt`：写 prompt、模型、seed、参数，便于复现
- 只放**最终可用**的图；中间产物、失败图放 `Temp/comfyui/`

---

## 工作流

```
训练素材/图像  ──学习──▶  归纳.md
                          │
                          ▼
                   ComfyUI 生图（本目录）
                          │
                          ├─ 选中 → 进 3D（Tripo / TripoSR）
                          └─ 选中 → 进 Unity（2D 资产）
```

## 生成命令

```powershell
python Tools\ComfyUI\generate.py --prompt "..." --out 训练成果\图像\设备\加热机_概念_01.png
```

参数、模型、seed 会写进同名 `.txt`，不靠记忆。

## 版权与体积

- 生成图默认**进 git**（是交付物）；单张 ≤ 5 MB
- 用了 LoRA / 参考图时，在 `.txt` 里注明来源与许可
