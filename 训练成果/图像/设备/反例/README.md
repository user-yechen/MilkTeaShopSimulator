# 反例（Negative Samples）

> 存「明确错在哪」的废稿，用途是**人工复盘 + 回归测试 + 写负面提示词**，
> **不是**给模型当参考图（img2img 喂反例只会学坏）。

## 放什么

- 结构错了的图：杆变成把手、U 形环、锥形桶、消失、贴回机身
- 凹槽/托盘错了的图：托盘悬空、凹槽糊平、托盘不齐底
- 蒸汽、杯子、文字等不该出现的元素

## 命名

`反例_<图号>_<问题>.png`，例如：

```
反例_34_U形环.png
反例_27_杆变锥桶.png
反例_35_杆碎成方块.png
```

同名 `.txt` 写一句「错在哪、正确应该是什么」。

## 怎么用

1. **验收清单**：每轮出图先对照反例，出现同类问题直接弃
2. **负面提示词**：把反例里的问题词加进 `--negative`（handle、U shape、bracket、cone…）
3. **回归测试**：改底图/换模型后，重跑同一 prompt，确认不再犯
4. 若以后训 LoRA：反例可做负样本，但需要**成对数据**（同 prompt 的正/负样本），单张废稿不够

## 边界

- 反例不参与 `训练素材/图像` 的风格归纳
- 每类问题留 1–2 张即可，不要囤几十张
