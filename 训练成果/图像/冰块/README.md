# 冰块堆（冰柜储备）

> 按前制作台凹槽尺寸生成的三档冰块堆：低 / 中 / 高。
> 凹槽来源：`D:\Blender\前制作台.blend` 的 Cube.001 —— **2.82 × 4.32 × 0.398**（x ±1.41，y -9.22~-4.90，z 0.178~0.576）。

## 三张图

| 文件 | 块数 | 堆高 | 表现 |
|---|---:|---:|---|
| `冰块_低.png` | 18 | ~0.09 | 薄薄一层、散在底部 |
| `冰块_中.png` | 55 | ~0.22 | 半满、覆盖大部分底面 |
| `冰块_高.png` | 110 | ~0.38 | 接近满槽、堆到上沿 |

- 底面按凹槽 2.82 × 4.32 收缩 2%，方块 0.34–0.46（约 3–4 cm，按 1 单位 = 10 cm）
- 1024×1024、白底、3/4 俯视、倒角低模
- **不含容器**：容器在 Unity/前制作台里，模型只做冰堆

## 生成

```powershell
& D:\Blender\blender.exe -b -P Tools\3D\make_ice_bin.py -- `
  --level mid --out 训练成果\图像\冰块\冰块_中.png `
  --glb ArtSource\3D\final\冰块_中.glb --size 1024
```

`--level` 取 `low / mid / high`；块数/堆高/尺寸在脚本顶部 `CONF`。

## 备注

- `前制作台lv1.blend` 实际是**空的**（只有 8 个顶点的方盒 3.48×19.45×1.15，没有凹槽）；带凹槽的是 `前制作台.blend` 的 Cube.001，里面有 8 个小方槽。这里按**外框整体**当冰槽，忽略内部分隔。
- `冰块.blend` 里只有一个 1.98×1.98×2.0 的倒角立方体，没有堆形可复用；沿用了它的「倒角方块」语言。
- 已同时导出 GLB：`ArtSource/3D/final/冰块_{低,中,高}.glb`，Tripo 不理想时可直接用。
