# 摆放与穿模规范（Socket 方案）

> 2026-11-27　｜　解决「两个物件贴合但不穿模」靠手调坐标的问题
> 适用：杯子上机、成品上台、货架取放、升级换模、手持物品

---

## 0. 根因

现在调穿模的方式是：**在 Scene 里拖着看，觉得穿就挪 0.01，反复试**。
根因不是美术不够细，是三件事没定：

1. **没有挂点**：每个设备自己写 `slotY = -0.65 / -0.55` 这种魔法数，换模型就得重调。
2. **pivot 不统一**：有的在底面中心，有的在网格中心，落位只能靠试。
3. **用视觉对齐代替数据对齐**：眼睛判断「贴合」，但共面会 z-fighting，留缝会漏光。

**解法：把「摆在哪」从美术手里拿走，变成由挂点 + 包围盒算出来的确定值。**

---

## 1. 四条原则

| 原则 | 做法 |
|---|---|
| **不追求面贴合** | 允许 1–3 mm 穿插或 0.5–1 mm 间隙；完全共面必然闪（z-fighting） |
| **接缝靠遮挡** | 倒角边、裙边、接触阴影（blob shadow）、垫片，比几何精确更有效 |
| **挂点决定位置** | 设备提供 Socket，物品提供 Mountable，运行时算，不手填 |
| **自动校验** | 用包围盒检查悬空/过穿/共面，不靠肉眼 |

**容差标准（低模 + 移动端）**

| 场景 | 允许穿插 | 允许间隙 |
|---|---:|---:|
| 杯子落台面 | ≤ 3 mm | ≤ 1 mm |
| 设备贴墙/贴地 | ≤ 5 mm | ≤ 2 mm |
| 货架物品 | ≤ 3 mm | ≤ 1 mm |
| 装饰小件 | ≤ 2 mm | ≤ 1 mm |

> 共面容差：两个面距离 < 0.1 mm 视为「会闪」，必须推开或重叠 1 mm 以上。

---

## 2. 数据规范

每个可摆放物必须满足：

- **Pivot = 底面中心**（已有规范；`PivotToBottomCenter` 工具）
- 记录三个量（导入时自动测，存到 Prefab 的 Mountable 上）：
  - `footprint`：XZ 占地（米）
  - `height`：高度
  - `bottomOffset`：pivot 到底面的距离（pivot 在底面时为 0）
- 测量用网格本地包围盒（`ModelMeasurer`），**不要用 Renderer.bounds**（旋转会膨胀）

## 3. 三个组件

### 3.1 Socket（挂在设备上）

```csharp
public class Socket : MonoBehaviour
{
    public string socketType = "cup";     // cup / item / machine / hand
    public Vector3 size = new Vector3(0.2f, 0.2f, 0.2f); // 可放区域
    public float gap = 0.001f;            // 落位间隙（米）
    public Vector3 localForward = Vector3.forward;

    public Vector3 WorldForward => transform.TransformDirection(localForward);
}
```

- 一个空物体，放在「杯底应该接触的平面」上，朝向决定物品朝向
- 升级换模时，Socket 由新模型自带，位置跟模型走，**不需要重新调数值**

### 3.2 Mountable（挂在可摆放物上）

```csharp
public class Mountable : MonoBehaviour
{
    public string mountType = "cup";
    public Vector3 footprint;
    public float height;
    public float bottomOffset;   // pivot→底面
}
```

### 3.3 PlacementService（统一摆放）

```csharp
public static class PlacementService
{
    /// 把 item 底面贴到 socket 平面，朝向对齐 socket
    public static void Place(GameObject item, Socket socket)
    {
        var m = item.GetComponent<Mountable>();
        float lift = (m != null ? m.bottomOffset : 0f) + socket.gap;

        Bounds b = GetLocalBounds(item);              // 世界 AABB
        float bottomWorld = b.min.y;                  // 假设支撑面水平
        float deltaY = (socket.transform.position.y + lift) - bottomWorld;

        item.transform.position += Vector3.up * deltaY;
        item.transform.rotation = Quaternion.LookRotation(
            socket.WorldForward, Vector3.up);
    }

    public static Bounds GetLocalBounds(GameObject go) { /* 网格角点换算，跳过粒子 */ }
}
```

> 关键：**先按包围盒算 delta，再一次性平移**，不要累加微调。

## 4. 编辑器工具

### 4.1 吸附（`SocketSnapTool`）

菜单：`奶茶店/摆放/吸附到最近 Socket`

- 选中物品 → 找 3 m 内最近的 Socket → `PlacementService.Place`
- 支持 Undo；批量选中时逐个吸附
- 吸附后打印：底面误差、朝向误差

### 4.2 校验（`PlacementValidator`）

菜单：`奶茶店/摆放/检查穿模与悬空`

检查项：

| 检查 | 判定 | 修复 |
|---|---|---|
| 悬空 | 底面与支撑面距离 > 2 mm | 自动下移贴合 |
| 过穿 | 与支撑物包围盒重叠 > 5 mm | 自动上移 |
| 共面 | 两个面距离 < 0.1 mm | 推开 1 mm |
| 轴心偏 | pivot 不在底面中心 | 提示用 PivotToBottomCenter |
| 无 Socket | 设备缺挂点 | 提示补 Socket |

输出：`Temp/placement_report.txt` + Console 汇总。

## 9. 一句话

> **穿模不是调出来的，是算出来的。**
> 挂点定位置、包围盒定高度、容差定松紧、校验定对错——手调只留给「审美级」的 1 mm 微调。
