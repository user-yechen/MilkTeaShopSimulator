# 微信小游戏发布指南（Unity 项目）

> 2026-11-28　｜　目标：把《奶茶店模拟器》发到微信
> 结论先说：**Unity 项目不能直接当「小程序」，要走「小游戏」路线**（Unity WebGL → 微信小游戏转换）。

---

## 0. 先确认三件事（不确认后面都白做）

| 事项 | 说明 |
|---|---|
| **主体** | 个人 / 企业。个人主体能注册小游戏，但可发布的类目和变现受限；正式上线通常要企业主体 |
| **版号 / 备案** | 国内正式上线游戏类目，微信通常要求《游戏版号》或备案信息；没有版号一般只能做到**体验版**（限人数、不能正式发布） |
| **类目** | 小游戏 → 休闲游戏。类目决定审核材料（软著、版号、隐私政策） |

> 具体材料以微信公众平台「小游戏 - 设置 - 基本设置 / 类目」当前要求为准，政策会变。

---

## 1. 账号与工具

> **当前环境检查结果（2026-11-28）**：本机 Unity 2022.3.56f1c1 **没有安装 WebGL Build Support**，
> 也没有装微信小游戏插件。第一步必须先补 WebGL 模块。

0. **安装 WebGL 模块**：Unity Hub → 安装 → 2022.3.56f1c1 → 添加模块 → 勾选 **WebGL Build Support** → 安装（约 1–2 GB）
1. 微信公众平台注册 **小游戏**（不是小程序），拿到 **AppID**
2. 下载 **微信开发者工具**（稳定版）
3. 安装 **Unity 微信小游戏插件**（官方仓库 `wechat-miniprogram/minigame-unity-webgl-transform`，按 README 用 Unity Package Manager 添加）
   - 支持 Unity 2021.3 / 2022.3 LTS，本项目 2022.3.56f1c1 可用

---

## 2. Unity 侧改造清单

| 项 | 做什么 | 本项目现状 |
|---|---|---|
| 平台 | Switch Platform → **WebGL**，IL2CPP | 目前只有 Android |
| 压缩 | WebGL 发布压缩选 **Brotli**（需服务器支持）或 Gzip | 未配置 |
| 音频 | 转 **OGG**，减少首包 | 目前是 WAV（day 3.5MB + night 4.7MB） |
| 纹理 | ASTC / ETC2，关闭不必要的 Mipmap | 未检查 |
| 分辨率 | 按手机竖屏/横屏定 Canvas 与相机 FOV | 现为横屏 800×600 |
| 输入 | 触屏摇杆 / 按钮 | 已有 VirtualJoystick，需真机验证 |
| 存档 | PlayerPrefs → 微信存储适配（插件自带） | gameTime.json 走文件，**必须改** |
| 首包 | 资源放 CDN，首包只留启动必需 | 未做 |

> 存档是硬伤：WebGL 下 `Application.persistentDataPath` 不可写，需改成 PlayerPrefs 或微信存储 API。

---

## 3. 构建与转换

1. Unity 菜单：**微信小游戏 → 转换 / Build**（插件提供）
2. 生成 `webgl/` 目录 + 小游戏工程结构
3. 微信开发者工具「导入项目」→ 选生成的目录 → 填 AppID
4. 模拟器跑通 → **真机预览**（扫码）
5. 真机上重点看：触控、音频自动播放限制、首屏加载、发热

---

## 4. 包体预算

微信小游戏对包体有硬限制（主包约 4MB、总分包约 20MB，以最新规则为准）。

本项目 APK 33MB，WebGL 预计 **40MB+**，必须：

- 音频 WAV → OGG（8MB → 1MB 以内）
- 纹理压缩 + 分辨率下调
- 大资源放 CDN，运行时按需加载
- 场景按需加载（Addressables 或 AssetBundle）

---

## 5. 上线流程

```
注册小游戏 → 拿 AppID → 本地跑通（模拟器 + 真机）
→ 上传体验版 → 真机验收 → 提交审核（类目/版号/隐私政策）
→ 审核通过 → 发布
```

审核常见卡点：

- 无版号 / 类目不符
- 隐私政策缺失（收集了设备信息却没声明）
- 首屏加载超时、黑屏
- 诱导分享 / 诱导关注

---

## 6. 本项目待办（按优先级）

1. **存档改造**：`GameTimeStore` 从文件改为 PlayerPrefs（WebGL 兼容）
2. **音频压缩**：WAV → OGG（可用 ffmpeg；本机暂无，需安装或找替代）
3. **包体评估**：先出一次 WebGL 构建，看实际体积再决定 CDN 方案
4. **真机性能**：中低端安卓机跑 30FPS
5. **隐私政策**：小游戏后台填写，页面内提供入口
6. **素材**：截图、录屏、icon（小游戏要求尺寸）

---

## 7. 备选方案

| 方案 | 可行性 | 说明 |
|---|---|---|
| 微信小游戏（Unity 转换） | ✅ 推荐 | 官方支持，改动可控 |
| 小程序 web-view 嵌 H5 | ❌ | 小程序 web-view 不能跑 Unity WebGL，且个人主体受限 |
| 只发 Android APK | ✅ 现状 | 最简单，但不是微信渠道 |
| 抖音/快手小游戏 | ⚠️ | 也支持 Unity 转换，但同样要版号 |
