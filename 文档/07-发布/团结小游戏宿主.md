# 团结引擎「小游戏宿主」上传指南（minihost.tuanjie.cn）

> 2026-11-28　｜　替代 CrazyGames 的国内方案：不用 Google 账号、不用版号（以平台规则为准）
> 平台：Unity 中国 / 团结引擎的 **小游戏宿主**

---

## 1. 它是什么

- 把 Unity 项目打成 **宿主小游戏包**，上传到 `minihost.tuanjie.cn`
- 用 **Connect App** 扫码运行（官方测试宿主）
- 支持 **广告、登录、存储** 等能力（`minihost.TJ` API，和微信 `WX` 一一对应）
- 支持 **CDN + 分包**，单包上限 **300 MB**

> 它是「宿主分发」平台，不是微信/抖音那种流量入口；实际量取决于接入宿主 SDK 的 App。

## 3. 上传步骤

### 3.0 构建脚本（已内置）

`Assets/Editor/BuildScript.cs` 新增：

| 菜单 | 作用 |
|---|---|
| `奶茶店/构建/检查小游戏宿主环境` | 打印 WebGL 模块、插件是否已装 |
| `奶茶店/构建/安装小游戏宿主插件` | `Client.Add("cn.tuanjie.minihost")` |
| `奶茶店/构建/小游戏宿主（打开构建窗口）` | 打开插件构建窗口填 Game Id |
| `奶茶店/构建/WebGL` | 通用 WebGL 构建（Gzip + fallback） |

命令行：

```powershell
Unity.exe -batchmode -quit -projectPath D:\UnityProject\milktea -buildTarget WebGL `
  -executeMethod BuildScript.BuildWebGL -logFile Build/build-webgl.log
```

WebGL 设置已固定：IL2CPP/Release、Strip Engine Code、Gzip、decompression fallback。

### 3.1 后台建游戏

1. 后台 `minihost.tuanjie.cn` → **新增小游戏** → 填名称/简介/标签/图标
   - 创建后默认「已停用」，上传发布后变「已启用」
2. Unity：菜单「奶茶店/构建/安装小游戏宿主插件」；或 Package Manager → Add package by name → `cn.tuanjie.minihost`
3. 菜单 **小游戏宿主 → 构建**，填：
   - **Game Id**（后台创建后拿）
   - 导出路径、启动背景图、游戏方向（横屏）
   - 首包资源加载方式：包内 / CDN
   - 预分配堆大小：超休闲 256 MB
   - 自动上传至宿主平台 ✓
4. 点 **生成并转换** → 生成 `game.zip`
5. 后台上传 `game.zip`（≤300 MB），或构建时自动上传
6. 用 **Connect App** 扫码体验
7. 需要更大包体时用后台的 **分包管理**
