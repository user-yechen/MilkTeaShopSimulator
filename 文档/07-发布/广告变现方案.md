# 广告变现方案（个人开发者 / 无版号）

> 2026-11-28　｜　前提：个人主体，没有游戏版号
> 结论：**国内应用商店和小游戏都走不通**；个人能合法跑通的只有「海外 Web」或「海外应用商店」。

---

## 1. 三条路线对比

| 路线 | 门槛 | 流量 | 广告收入 | 合规 |
|---|---|---|---|---|
| **海外 Web**（CrazyGames / Poki / itch.io） | 低，个人可注册 | 平台自带流量，靠推荐位 | 分成 + 平台广告 | 低，无需版号 |
| **Google Play + AdMob** | 中，$25 开发者号；新个人号需 12 名测试员 14 天 | 靠自己买量/ASO | eCPM 较高 | 中，需隐私政策、数据安全表 |
| **国内 Android + 穿山甲/优量汇** | 高：应用商店上架要版号；广告平台多要企业资质 | 国内安卓渠道 | 中等 | 高，无版号属违规运营 |

> 微信小游戏同理：游戏类目要企业 + 版号，个人只能体验版，接不了流量主广告。

---

## 2. 推荐：先上海外 Web

适合这个 Demo：体量小、单局短、WebGL 能跑。

1. 出 **WebGL 构建**（见 `微信小游戏.md` 的包体优化部分）
2. 接平台 SDK 的广告：
   - **CrazyGames SDK**：`gameplayStart/Stop`、`showAd('rewarded'/'midgame')`
   - **Poki SDK**：类似
   - itch.io：不强制 SDK，可外链赞助
3. 上传过审（平台会看加载速度、可玩性、是否有外链）

优点：不用版号、不用买量、平台给曝光；缺点是分成比例一般（约 30–50%）。

---

## 3. 备选：Google Play + AdMob

- Unity 接 **Google Mobile Ads Unity Plugin**
- 先跑 **测试广告**（TestAdUnitId），确认不影响玩法
- 新个人开发者账号要 **12 名测试员连续测试 14 天** 才能发布
- 必须：隐私政策、Data Safety 表单、UMP 同意弹窗（欧盟）

---

## 4. 广告形式与植入点（针对本游戏）

| 形式 | 放哪 | 说明 |
|---|---|---|
| **激励视频** | 打烊结算页「双倍营收」 | 最自然，玩家主动看 |
| **激励视频** | 营业中「加速 30 秒」 | 时间压力大时愿意看 |
| **激励视频** | 冰格空了「免费补满冰」 | 和冰块储备系统直接挂钩 |
| **插屏** | 进入下一天前 | 频率控制在每 2–3 天一次 |
| **Banner** | 商店/设置页底部 | 不要挡住操作区 |

原则：**广告不能打断核心循环**，只放在「结算 / 等待 / 资源不足」这三个点。

---

## 5. 技术接入建议

先做一层抽象，避免以后换平台重写：

```csharp
public interface IAdService {
    bool IsRewardedReady { get; }
    void ShowRewarded(string placement, System.Action<bool> onResult);
    void ShowInterstitial();
}
```

- 编辑器/开发期用 `MockAdService`（直接回调成功）
- Web 用 `CrazyGamesAdService`，Android 用 `AdMobAdService`
- 所有广告调用带 `placement` 字符串，方便后台看哪个点收益高

---

## 6. 合规清单（个人也躲不开）

- 隐私政策页面（收集了设备信息 / 广告 ID 就要写）
- 首次启动的隐私同意弹窗（海外 GDPR / 国内个保法）
- 未成年人保护：广告内容分级、避免诱导充值
- 国内无版号运营游戏属违规，不要抱侥幸

---

## 7. 收入预期（保守）

| 指标 | 海外 Web | 海外 App |
|---|---|---|
| 激励视频 eCPM | $3–8 | $8–20 |
| 插屏 eCPM | $1–3 | $3–8 |
| 日活 1,000 的日收入 | $5–15 | $15–40 |

Demo 阶段重点不是收入，是**验证留存**：次日留存 <20% 的话，广告放再多也没用。
