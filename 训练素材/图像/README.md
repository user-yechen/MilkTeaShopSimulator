# 图像素材

> 喂给 **2D 美术 / 3转2 图标 / 3D 模型 Agent**。放参考图、风格板、图标、截图。

## 放什么

| 类型 | 格式 | 说明 |
|---|---|---|
| 风格参考 | png / jpg / webp | 整体风格、配色、氛围 |
| 图标参考 | png（透明底） | 按钮、功能图标、货币 |
| 产品图 | png（透明底） | 杯子、小料、包装 |
| 截图 | png / jpg | 竞品界面、布局、交互 |
| 风格板 | jpg / png | 多张拼一张 moodboard |

## 命名与标注

`来源_主题_序号.扩展名`，例如 `参考_奶茶店招牌_01.png`。

超过 3 张同类图，建议拼一张风格板，文件名加 `_board`。

## Agent 学什么

- 主色 / 辅色（可量化成 HEX）
- 明度与饱和度区间
- 造型语言（圆角 / 倒角 / 描边 / 扁平）
- 材质与光照（哑光 / 高光 / 透明）
- 构图与视角（正视 / 3/4 / 俯视）
- 图标尺寸与留白比例

## 产出

`图像/归纳.md`（按 `../_归纳模板.md`），结论提炼进：

- `文档/02-规范/美术风格.md`（色板、造型、UI）
- `文档/06-Agents/2D美术Agent.md`、`3转2图标Agent.md`、`3D模型Agent.md`（风格与验收）

## 注意

- 只放有权使用的图；来源不明不要放
- 单张 ≤ 5 MB；超过 2K 的图先缩到 1024–2048
- 透明底图保留 alpha，不要压成白底 JPG
