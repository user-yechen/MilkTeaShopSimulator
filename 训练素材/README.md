# 训练素材

> 给 Agent 学习用的参考素材库。**不是运行时资源**，不参与 Unity 导入。
> 三个子目录分别喂给不同 Agent，归纳结果写回各自的 `归纳.md`，再提炼进规范文档。

---

## 目录

| 目录 | 放什么 | 谁来学 | 归纳产出 |
|---|---|---|---|
| [音乐/](音乐/) | 参考曲、Loop、MIDI、音色说明 | 音乐 Agent | `音乐/归纳.md` |
| [文案/](文案/) | 文案样本、大纲、竞品文案、台词 | 文案 Agent | `文案/归纳.md` |
| [图像/](图像/) | 参考图、风格板、图标、截图 | 2D 美术 / 3转2 / 3D 模型 Agent | `图像/归纳.md` |

---

## 怎么用（三步）

1. **放素材**：按子目录的 README 命名后丢进去
2. **让 Agent 学**：说一句「让音乐 Agent 读训练素材/音乐 并归纳」
3. **Agent 执行**：
   - 跑 `python Tools/Training/scan_materials.py` 生成清单（数量/格式/尺寸/重复）
   - 抽样读内容（图片看、音频看参数、文案读文本）
   - 写 `<子目录>/归纳.md`：共性特征、可复用规则、禁用项、待确认
   - 你确认后，把结论提炼进 `文档/02-规范/美术风格.md`、`文档/06-Agents/音乐Agent.md` 等

---

## 命名规范

`来源_主题_序号.扩展名`

```
参考_日系轻快_01.mp3
参考_奶茶店招牌_02.png
竞品_点单提示_03.txt
```

- 来源：`参考` / `竞品` / `自研` / `AI`
- 主题：2–6 个字，能看出是什么
- 序号：两位数，同一主题递增

---

## 版权与体积

- **只放你有权使用的素材**（自己录/买/CC0/授权）；来源不明的图不要放
- 单个文件建议：音频 ≤ 20 MB、图片 ≤ 5 MB、文本 ≤ 1 MB
- 整个 `训练素材` 建议 ≤ 500 MB；超了先压缩或只留切片
- 素材默认**不进 git**（见 `.gitignore`），只提交 `README.md` 与 `归纳.md`
