# 文案素材

> 喂给 **文案 Agent**。放文案样本、大纲、竞品文案、台词。

## 放什么

| 类型 | 格式 | 说明 |
|---|---|---|
| 文案样本 | .txt / .md / .docx | 你觉得「写得像这样」的文案 |
| 大纲 / 草稿 | .md / .docx | 待润色的原始大纲 |
| 竞品文案 | .txt | 从截图转写下来的文字（注明来源） |
| 台词 / 顾客语料 | .txt | 不同语气、不同角色 |

## 命名与标注

`来源_场景_序号.扩展名`，例如 `竞品_点单提示_01.txt`。

文件开头建议写三行元信息：

```
场景：打烊结算
语气：温暖、简短
字数：≤ 20 字
```

## Agent 学什么

- 句式（陈述 / 疑问 / 感叹的比例）
- 平均字数与上限
- 称呼（你 / 客人 / 老板）
- 标点习惯（全角、省略号、破折号）
- 语气词与禁用词
- 信息顺序（先说结论还是先解释）

## 产出

`文案/归纳.md`（按 `../_归纳模板.md`），结论提炼进 `文档/06-Agents/文案Agent.md`。

## 注意

- 素材要脱敏：不要放真实姓名、电话、地址
- 竞品文案只做风格参考，不要整段照搬
- 单个文件 ≤ 1 MB；.docx 请确认能正常打开
