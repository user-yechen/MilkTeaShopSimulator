# 音乐素材

> 喂给 **音乐 Agent**。放参考曲、Loop、MIDI、音色说明。

## 放什么

| 类型 | 格式 | 说明 |
|---|---|---|
| 参考曲 | mp3 / wav / flac / ogg | 想要「像这种」的整首或片段，30 s–3 min |
| Loop | wav / ogg | 可直接循环的片段，注明小节数 |
| MIDI | .mid | 有编曲参考价值的旋律/和弦 |
| 音色说明 | .txt / .md | 用了什么乐器、什么音源、混音参数 |

## 命名与标注

`参考_主题_序号.扩展名`，例如 `参考_日系轻快_01.mp3`。

建议在文件名里带上关键参数，或放同名 `.txt`：

```
参考_日系轻快_01.mp3
参考_日系轻快_01.txt   → BPM 96 / C 大调 / 钢琴+吉他+轻鼓 / 循环 16 小节
```

## Agent 学什么

- BPM 与调式分布
- 和声走向（每几小节换和弦）
- 配器与层次（主奏 / 铺底 / 节奏）
- 动态与段落（A/B 段怎么进）
- 混音倾向（低频多少、Pad 多宽）
- Loop 长度与循环点处理

## 产出

`音乐/归纳.md`（按 `../_归纳模板.md`），结论提炼进 `文档/06-Agents/音乐Agent.md` 与 `文档/02-规范/美术风格.md` 的音频部分。

## 注意

- 只放有权使用的素材；不要放整张商业专辑
- 单个文件 ≤ 20 MB；多首参考建议只留 30–60 s 切片
